## 🚀 របៀបប្រើប្រាស់ (How to Use):
1. **វិធីទី ១ - បិទភ្ជាប់ផ្ទាល់ (Quick Copy-Paste)**:
   - បើកឯកសារ `.tsv` ណាមួយ ឬចម្លងតារាងខាងលើ (Ctrl+A -> Ctrl+C)
   - ចូលកម្មវិធី Voatmean -> ចុចប៊ូតុង **"នាំចូល Sheet"** (Import Sheet)
   - ចុចប៊ូតុង **"បិទភ្ជាប់ Clipboard"**
   - ប្រព័ន្ធនឹងវិភាគទិន្នន័យ (Smart Parsing) ដោយស្វ័យប្រវត្តិ រួចចុច **"នាំចូលទិន្នន័យ"**!

2. **វិធីទី ២ - ប៊ូតុងទិន្នន័យគំរូក្នុង App (In-App Sample Button)**:
   - ពេលបើកផ្ទាំង Smart Import Modal ឡើងមក លោកអ្នកគ្រាន់តែចុចលើប៊ូតុងបៃតង **"✨ ទិន្នន័យគំរូ"**
   - វានឹងបញ្ចូលទិន្នន័យគំរូត្រឹមត្រូវភ្លាមៗ ដោយមិនបាច់ទៅចម្លងពីខាងក្រៅ!
